Deezer Standalone

Keep the server window open and play music on Deezer with the userscript enabled.

  1. Open / install the userscript. If your browser only displays code, copy it into a new script in Tampermonkey or Violentmonkey and save it. Disable your old Tuna script.
  2. Reload Deezer and play a song. Allow the userscript to connect to 127.0.0.1 if prompted.
  3. Open your overlay: Flat (520 × 112) · Glass (540 × 118) · Tiny Corner (420 × 92)

Use the overlay URL in your browser or streaming app. In a Browser Source, disable Local file and paste the URL. A browser window does not automatically float above other applications.
